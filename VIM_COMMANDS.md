# Шпаргалка по Vim — полный справочник команд

> Vim — модальный редактор, в котором одни клавиши перемещают курсор, другие вставляют текст, третьи выполняют операции. Режим определяет, что делает каждое нажатие.

---

## Режимы Vim

| Режим | Как войти | Как выйти |
|-------|-----------|-----------|
| **Normal** (нормальный) | По умолчанию при открытии | — |
| **Insert** (вставка) | `i`, `a`, `o`, `I`, `A`, `O`, `s`, `S` | `Esc` |
| **Visual** (выделение) | `v`, `V`, `Ctrl+v` | `Esc` |
| **Command** (командная строка) | `:` | `Esc` или `Enter` |
| **Replace** (замена) | `R` | `Esc` |
| **Search** (поиск) | `/` или `?` | `Esc` или `Enter` |

---

## 1. Навигация (Normal mode)

### Базовое перемещение курсора

| Команда | Действие |
|---------|----------|
| `h` | Влево на один символ |
| `l` | Вправо на один символ |
| `j` | Вниз на одну строку |
| `k` | Вверх на одну строку |
| `0` | В начало строки |
| `^` | К первому непробельному символу строки |
| `$` | В конец строки |
| `g_` | К последнему непробельному символу строки |

### Перемещение по словам

| Команда | Действие |
|---------|----------|
| `w` | Вперёд к началу следующего слова |
| `W` | Вперёд к началу следующего СЛОВА (через пробелы) |
| `b` | Назад к началу текущего/предыдущего слова |
| `B` | Назад к началу СЛОВА |
| `e` | К концу текущего слова |
| `E` | К концу СЛОВА |
| `ge` | Назад к концу предыдущего слова |

### Перемещение по файлу

| Команда | Действие |
|---------|----------|
| `gg` | В начало файла |
| `G` | В конец файла |
| `5G` | На строку 5 (любое число + G) |
| `:42` | Перейти на строку 42 |
| `%` | К парной скобке `()`, `[]`, `{}` |
| `{` | К предыдущему пустому абзацу |
| `}` | К следующему пустому абзацу |
| `H` | К верхней строке экрана |
| `M` | К средней строке экрана |
| `L` | К нижней строке экрана |

### Прокрутка

| Команда | Действие |
|---------|----------|
| `Ctrl+f` | Прокрутить вниз на весь экран |
| `Ctrl+b` | Прокрутить вверх на весь экран |
| `Ctrl+d` | Прокрутить вниз на пол-экрана |
| `Ctrl+u` | Прокрутить вверх на пол-экрана |
| `Ctrl+e` | Прокрутить экран вниз (курсор остаётся) |
| `Ctrl+y` | Прокрутить экран вверх (курсор остаётся) |
| `zz` | Центрировать экран на курсоре |
| `zt` | Курсор — в верхнюю строку экрана |
| `zb` | Курсор — в нижнюю строку экрана |

### Поиск символа в строке

| Команда | Действие |
|---------|----------|
| `f{x}` | Перейти к следующему символу `x` в строке |
| `F{x}` | Перейти к предыдущему символу `x` в строке |
| `t{x}` | Перейти к символу перед `x` |
| `T{x}` | Перейти к символу после `x` (назад) |
| `;` | Повторить последний `f/F/t/T` вперёд |
| `,` | Повторить последний `f/F/t/T` назад |

---

## 2. Вход в режим Insert

| Команда | Действие |
|---------|----------|
| `i` | Вставить перед курсором |
| `I` | Вставить в начало строки |
| `a` | Вставить после курсора |
| `A` | Вставить в конец строки |
| `o` | Открыть новую строку ниже и войти в Insert |
| `O` | Открыть новую строку выше и войти в Insert |
| `s` | Удалить символ под курсором и войти в Insert |
| `S` | Удалить строку и войти в Insert |
| `C` | Удалить от курсора до конца строки и войти в Insert |

---

## 3. Редактирование текста (Normal mode)

### Удаление

| Команда | Действие |
|---------|----------|
| `x` | Удалить символ под курсором |
| `X` | Удалить символ слева от курсора |
| `dd` | Удалить строку (вырезать) |
| `D` | Удалить от курсора до конца строки |
| `dw` | Удалить слово вперёд |
| `db` | Удалить слово назад |
| `d0` | Удалить от курсора до начала строки |
| `d$` | Удалить от курсора до конца строки |
| `dgg` | Удалить от строки до начала файла |
| `dG` | Удалить от строки до конца файла |
| `diw` | Удалить слово под курсором |
| `daw` | Удалить слово под курсором с пробелами |
| `di"` | Удалить содержимое внутри кавычек `"` |
| `da"` | Удалить содержимое вместе с кавычками |
| `di(` | Удалить содержимое внутри скобок `()` |
| `dit` | Удалить содержимое HTML-тега |
| `3dd` | Удалить 3 строки |

### Копирование (yank)

| Команда | Действие |
|---------|----------|
| `yy` или `Y` | Скопировать строку |
| `yw` | Скопировать слово |
| `y$` | Скопировать до конца строки |
| `y0` | Скопировать до начала строки |
| `yiw` | Скопировать слово под курсором |
| `yi"` | Скопировать содержимое внутри кавычек |
| `3yy` | Скопировать 3 строки |
| `ygg` | Скопировать от курсора до начала файла |
| `yG` | Скопировать от курсора до конца файла |

### Вставка

| Команда | Действие |
|---------|----------|
| `p` | Вставить после курсора / под строкой |
| `P` | Вставить до курсора / над строкой |
| `gp` | Вставить и переместить курсор за вставленный текст |

### Изменение (change = удалить + войти в Insert)

| Команда | Действие |
|---------|----------|
| `cc` | Изменить всю строку |
| `cw` | Изменить слово вперёд |
| `ciw` | Изменить слово под курсором |
| `ci"` | Изменить содержимое внутри кавычек |
| `ci(` | Изменить содержимое внутри скобок |
| `c$` | Изменить до конца строки |
| `c0` | Изменить до начала строки |

### Замена

| Команда | Действие |
|---------|----------|
| `r{x}` | Заменить символ под курсором на `x` |
| `R` | Режим замены (перезаписывать символы) |
| `~` | Переключить регистр символа |
| `g~w` | Переключить регистр слова |
| `guw` | Перевести слово в нижний регистр |
| `gUw` | Перевести слово в верхний регистр |
| `guu` | Перевести строку в нижний регистр |
| `gUU` | Перевести строку в верхний регистр |

### Отмена и повтор

| Команда | Действие |
|---------|----------|
| `u` | Отменить последнее действие |
| `U` | Отменить все изменения в текущей строке |
| `Ctrl+r` | Повторить отменённое действие |
| `.` | Повторить последнюю команду изменения |

### Отступы и форматирование

| Команда | Действие |
|---------|----------|
| `>>` | Сдвинуть строку вправо (добавить отступ) |
| `<<` | Сдвинуть строку влево (убрать отступ) |
| `>ip` | Сдвинуть весь параграф вправо |
| `=` | Автоформатирование выделенного |
| `==` | Автоформатировать строку |
| `gg=G` | Автоформатировать весь файл |
| `J` | Объединить строку со следующей |
| `gJ` | Объединить без добавления пробела |

## 4. Поиск и замена

### Поиск

| Команда | Действие |
|---------|----------|
| `/текст` | Поиск вперёд |
| `?текст` | Поиск назад |
| `n` | Следующее совпадение (по направлению поиска) |
| `N` | Предыдущее совпадение |
| `*` | Поиск слова под курсором вперёд |
| `#` | Поиск слова под курсором назад |
| `g*` | Поиск части слова вперёд |
| `g#` | Поиск части слова назад |

### Замена (командная строка)

| Команда | Действие |
|---------|----------|
| `:s/old/new` | Заменить первое вхождение в строке |
| `:s/old/new/g` | Заменить все в текущей строке |
| `:%s/old/new/g` | Заменить все в файле |
| `:%s/old/new/gc` | Заменить с подтверждением каждого |
| `:5,10s/old/new/g` | Заменить в строках 5–10 |
| `:%s/\bword\b/new/g` | Заменить только целые слова |
| `:%s/old/new/gi` | Заменить без учёта регистра |

---

## 5. Visual mode (режим выделения)

| Команда | Действие |
|---------|----------|
| `v` | Посимвольное выделение |
| `V` | Построчное выделение |
| `Ctrl+v` | Блочное выделение (прямоугольник) |
| `gv` | Повторно выделить последнее выделение |
| `o` | Переместить курсор на другой конец выделения |
| `aw` | Расширить выделение на слово |
| `ab` | Расширить выделение на блок `()` |
| `aB` | Расширить выделение на блок `{}` |

После выделения доступны:

| Команда | Действие |
|---------|----------|
| `d` | Удалить выделенное |
| `y` | Скопировать выделенное |
| `c` | Изменить выделенное |
| `>` / `<` | Сдвинуть отступ |
| `~` | Переключить регистр |
| `u` / `U` | В нижний / верхний регистр |
| `:` | Применить Ex-команду к выделению |

## 6. Работа с файлами и буферами

### Файловые операции

| Команда | Действие |
|---------|----------|
| `:w` | Сохранить файл |
| `:w имя` | Сохранить как `имя` |
| `:w!` | Принудительно сохранить |
| `:q` | Закрыть (если нет несохранённых изменений) |
| `:q!` | Закрыть без сохранения |
| `:wq` или `ZZ` | Сохранить и закрыть |
| `:e имя` | Открыть файл |
| `:e!` | Перезагрузить файл (отменить изменения) |
| `:r имя` | Вставить содержимое файла под курсором |
| `:saveas имя` | Сохранить под новым именем |

### Буферы

| Команда | Действие |
|---------|----------|
| `:ls` или `:buffers` | Показать список буферов |
| `:b N` | Переключиться на буфер N |
| `:bn` | Следующий буфер |
| `:bp` | Предыдущий буфер |
| `:bd` | Закрыть текущий буфер |
| `:badd имя` | Добавить файл в буфер |

### Разделение окон

| Команда | Действие |
|---------|----------|
| `:sp` или `Ctrl+w s` | Разделить горизонтально |
| `:vsp` или `Ctrl+w v` | Разделить вертикально |
| `Ctrl+w h/j/k/l` | Перейти в окно слева/снизу/сверху/справа |
| `Ctrl+w w` | Переключиться в следующее окно |
| `Ctrl+w q` | Закрыть текущее окно |
| `Ctrl+w =` | Выровнять размеры окон |
| `Ctrl+w +/-` | Увеличить / уменьшить высоту окна |
| `Ctrl+w >/<` | Увеличить / уменьшить ширину окна |

### Вкладки

| Команда | Действие |
|---------|----------|
| `:tabnew имя` | Открыть в новой вкладке |
| `:tabn` или `gt` | Следующая вкладка |
| `:tabp` или `gT` | Предыдущая вкладка |
| `:tabclose` | Закрыть вкладку |
| `:tabs` | Показать все вкладки |

## 12. Text objects — умные объекты

Формат: `{оператор}{i|a}{объект}`
- `i` — **inner** (внутри, без границ)
- `a` — **a/an** (включая границы)

| Объект | Пример | Действие |
|--------|--------|----------|
| `w` — слово | `diw` | Удалить слово |
| `s` — предложение | `das` | Удалить предложение с пробелом |
| `p` — параграф | `yip` | Скопировать параграф |
| `"` — двойные кавычки | `ci"` | Изменить содержимое `"..."` |
| `'` — одинарные кавычки | `ya'` | Скопировать с `'...'` |
| `(` или `b` — скобки | `di(` | Удалить содержимое `(...)` |
| `{` или `B` — фигурные | `ca{` | Изменить содержимое `{...}` |
| `[` — квадратные | `yi[` | Скопировать содержимое `[...]` |
| `<` — угловые | `di<` | Удалить содержимое `<...>` |
| `t` — HTML/XML тег | `cit` | Изменить содержимое тега |

---

## 13. Конфигурация `.vimrc` / vimscript

Пример базовой конфигурации `~/.vimrc`:

```vim
" Нумерация строк
set number
set relativenumber

" Отступы
set tabstop=4
set shiftwidth=4
set expandtab

" Поиск
set hlsearch      " подсветить результаты
set incsearch     " поиск по мере ввода
set ignorecase    " игнорировать регистр
set smartcase     " учитывать регистр при наличии заглавных

" Внешний вид
set cursorline    " подсветить строку курсора
syntax on
colorscheme desert

" Разное
set clipboard=unnamedplus   " использовать системный буфер обмена
set undofile                " постоянная история отмены
```

# Инструкция: как демонстрировать Vim в VS Code

## Шаг 1 — Установить расширение Vim

1. Открыть VS Code
2. Перейти в Extensions: `Ctrl+Shift+X`
3. Найти **"Vim"** от автора **vscodevim**
4. Нажать **Install**

После установки расширение автоматически активируется для всех файлов.

---

## Шаг 2 — Включить важные настройки

Открыть `settings.json` (`Ctrl+Shift+P` → "Open User Settings JSON") и добавить:

```json
{
    "vim.enable": true,
    "vim.useSystemClipboard": true,
    "vim.hlsearch": true,
    "vim.incsearch": true,
    "vim.leader": "<space>",
    "vim.useCtrlKeys": true,
    "vim.handleKeys": {
        "<C-d>": true,
        "<C-u>": true,
        "<C-f>": true,
        "<C-b>": true
    }
}
```

---

## Шаг 3 — Убедиться, что Vim активен

В нижней строке статуса VS Code появится индикатор режима:
- `-- NORMAL --` — нормальный режим
- `-- INSERT --` — режим вставки
- `-- VISUAL --` — режим выделения

---

## Шаг 4 — Практический сценарий демонстрации

Создайте файл `demo.py` или `demo.js` со следующим содержимым:

```python
def greet(name):
    print("Hello, " + name)
    print("Welcome to Vim!")
    return name

names = ["Alice", "Bob", "Charlie"]
for name in names:
    greet(name)
```

### Демонстрация команд по шагам:

**Навигация:**
1. Открыть файл — курсор в режиме Normal
2. Нажать `j` / `k` — движение по строкам
3. Нажать `w` / `b` — движение по словам
4. Нажать `gg` — перейти в начало, `G` — в конец
5. Нажать `$` — конец строки, `0` — начало

**Вставка текста:**
6. Поставить курсор на строку с `return`, нажать `o` — новая строка ниже
7. Написать `    print("Done!")`, нажать `Esc`

**Удаление и копирование:**
8. Нажать `dd` — удалить строку
9. Нажать `yy` — скопировать строку
10. Нажать `p` — вставить ниже

**Поиск:**
11. Нажать `/Hello` + `Enter` — найти "Hello"
12. Нажать `n` — следующее совпадение

**Замена:**
13. Ввести `:%s/name/user/g` + `Enter` — заменить все "name" на "user"

**Visual mode:**
14. Нажать `V` — выделить строку
15. Нажать `jj` — расширить выделение на 2 строки
16. Нажать `d` — удалить выделенное

**Повтор:**
17. Нажать `.` — повторить последнее действие

**Отмена:**
18. Нажать `u` несколько раз — отменять по шагам

---

## Шаг 5 — Полезные настройки для демонстрации в VS Code

Чтобы показать относительную нумерацию строк (помогает понять, куда идёт `5j`):
```json
"editor.lineNumbers": "relative"
```

Чтобы показать текущий режим Vim в строке статуса — расширение делает это автоматически.

---

## Шаг 6 — Режимы для демонстрации в порядке сложности

| Уровень | Что показать |
|---------|-------------|
| Начальный | `hjkl`, `i`/`Esc`, `:w`, `:q` |
| Базовый | `w/b/e`, `dd/yy/p`, `u/Ctrl+r`, `/поиск` |
| Средний | Text objects (`ciw`, `di"`), Visual mode, `:s///` |
| Продвинутый | Макросы (`q`), регистры, разделение окон |

---

## Краткая памятка для быстрого старта

```
Esc         → Normal mode (всегда)
i           → Insert mode
:w          → сохранить
:q!         → выйти без сохранения
hjkl        → навигация
dd          → удалить строку
yy + p      → скопировать и вставить
/текст      → поиск
u           → отмена
.           → повтор
```
