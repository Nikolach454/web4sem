# Исправления по результатам проверки

## 1. `filter_horizontal` — добавлен тег-справочник и M2M-связь

**Проблема:** `filter_horizontal` — обязательная настройка административной части, но в проекте не была реализована. Единственная M2M-связь (`User.roles`) использует промежуточную таблицу `through='UserRole'`, а Django запрещает `filter_horizontal` для таких полей.

**Решение:** добавлена новая модель `Tag` (справочник тегов) и M2M-поле `tags` в модели `Prosthesis` без промежуточной таблицы.

### `catalog/models.py` — новая модель `Tag`

```python
class Tag(models.Model):
    """Тег / ключевое слово для протеза (справочник)."""

    name = models.CharField(
        max_length=100,
        unique=True,
        verbose_name='Тег',
    )

    class Meta:
        verbose_name = 'Тег'
        verbose_name_plural = 'Теги'
        ordering = ['name']

    def __str__(self):
        return self.name
```

### `catalog/models.py` — поле `tags` в `Prosthesis`

```python
# M:N без промежуточной таблицы — демонстрация filter_horizontal в admin
tags = models.ManyToManyField(
    'Tag',
    blank=True,
    verbose_name='Теги',
    related_name='prostheses',
)
```

### `catalog/admin.py` — `TagAdmin` и `filter_horizontal`

```python
@admin.register(Tag)
class TagAdmin(admin.ModelAdmin):
    list_display = ('id', 'name', 'prostheses_count')
    list_display_links = ('id', 'name')
    search_fields = ('name',)
    readonly_fields = ('id',)

    @admin.display(description='Кол-во протезов')
    def prostheses_count(self, obj):
        return obj.prostheses.count()
```

```python
@admin.register(Prosthesis)
class ProsthesisAdmin(admin.ModelAdmin):
    ...
    # filter_horizontal — виджет двойного списка для M2M (обязательная настройка)
    filter_horizontal = ('tags',)

    fieldsets = (
        ('Основное', {'fields': ('id', 'name', 'prosthesis_type', 'description')}),
        ('Теги', {'fields': ('tags',)}),          # ← виджет filter_horizontal здесь
        ('Цена и изображение', {'fields': ('price', 'image', 'image_preview')}),
        ('Статус', {'fields': ('is_active', 'created_at')}),
    )
```

**Как проверить:** открыть `http://127.0.0.1:8000/admin/catalog/prosthesis/add/` — в секции «Теги» будет виджет двойного списка: слева доступные теги, справа выбранные.

## 2. `delete()` — живая демонстрация вместо комментария

**Проблема:** `delete()` был показан только в виде закомментированного кода с пометкой «не выполняется». Требование гласит «продемонстрировать в проекте» — значит, должен реально работать.

**Решение:** добавлена кнопка на странице `/catalog/orm-demo/`, которая реально выполняет `.delete()` и показывает результат.

### `catalog/views.py` — блок `delete()` в `orm_demo`

```python
# delete(): массовое удаление неактивных протезов — POST-запрос для безопасности
# Возвращает кортеж: (кол-во_удалённых, {'catalog.Prosthesis': кол-во})
delete_result = None
if request.method == 'POST' and request.POST.get('action') == 'delete_inactive':
    count, details = Prosthesis.objects.filter(is_active=False).delete()
    delete_result = f'Удалено {count} протезов. Детали: {details}'

# Количество неактивных (для отображения перед удалением)
inactive_count = Prosthesis.objects.filter(is_active=False).count()
```

### `catalog/templates/catalog/orm_demo.html` — форма с кнопкой

```html
<div class="card">
    <h2>delete() — массовое удаление</h2>
    <p>Пример: <code>Prosthesis.objects.filter(is_active=False).delete()</code><br>
       Возвращает кортеж: (кол-во_удалённых, {'catalog.Prosthesis': кол-во})</p>

    {% if delete_result %}
        <p style="color:green; font-weight:bold;">{{ delete_result }}</p>
    {% endif %}

    <p>Сейчас неактивных протезов: <strong>{{ inactive_count }}</strong></p>

    <form method="post">
        {% csrf_token %}
        <input type="hidden" name="action" value="delete_inactive">
        <button type="submit" class="btn btn-danger"
            onclick="return confirm('Удалить все неактивные протезы?')">
            Выполнить delete()
        </button>
    </form>
</div>
```

**Как проверить:**
1. Сначала выполнить `update()` — он деактивирует протезы без цены
2. Затем нажать «Выполнить delete()» — страница покажет, сколько записей удалено и детали по таблицам

## 3. `MEDIA_URL` — исправлен ведущий слеш

**Проблема:** `MEDIA_URL = 'media/'` без ведущего слеша. При такой настройке `{{ obj.image.url }}` в шаблоне генерирует относительный URL `media/filename.jpg` вместо абсолютного `/media/filename.jpg`, что ломает отображение изображений на страницах не в корне сайта.

**Решение:** в `config/settings.py`:

```python
# Было:
MEDIA_URL = 'media/'

# Стало:
MEDIA_URL = '/media/'
```

## 4. Поле `tags` в форме на сайте

Поле `tags` добавлено в `ProsthesisForm`, чтобы теги можно было назначать не только через админку, но и через веб-форму создания/редактирования протеза.

### `catalog/forms.py`

```python
class ProsthesisForm(forms.ModelForm):
    class Meta:
        model = Prosthesis
        fields = ['prosthesis_type', 'name', 'description', 'price', 'image', 'tags', 'is_active']
```
