ВОПРОСЫ:

Создание и применение миграций:
  1. python manage.py makemigrations   — создаёт файл миграции в catalog/migrations/
  2. python manage.py migrate          — применяет миграции к базе данных
  3. python manage.py showmigrations   — показывает статус всех миграций
  Файлы миграций: catalog/migrations/0001_initial.py, 0002_...py

Работа с QuerySet и менеджерами:
  QuerySet — это ленивый запрос к БД. Он не выполняется до момента
  обращения к данным (итерация, срезы, len(), print()).
  Менеджеры: objects (по умолчанию), можно создать свои (ActiveManager).
  Цепочки: Prosthesis.objects.filter(...).exclude(...).order_by(...)
  Каждый метод возвращает новый QuerySet, запрос к БД — один раз в конце.

Регулярные выражения в URLs:
  catalog/urls.py — re_path:
    re_path(r'^prostheses/(?P<pk>[0-9]+)/$', views.prosthesis_detail)
  Синтаксис:
    ^       — начало URL
    $       — конец URL
    [0-9]+  — одна или более цифр
    (?P<pk>...)  — именованная группа, передаётся в view как параметр pk
    \d+     — то же что [0-9]+, но короче

ЗАДАНИЕ: values() и values_list()

ЗАДАНИЕ: count() и exists()
ГДЕ СМОТРЕТЬ: catalog/views.py
  count()  — SELECT COUNT(*), возвращает число:

ВОПРОС: Использование кеш-фреймворка
  Django поддерживает несколько бэкендов кеша:
    - LocMemCache (в памяти процесса, по умолчанию)
    - FileBasedCache (в файлах)
    - Memcached / Redis
  Использование в view:
    from django.core.cache import cache
    data = cache.get('my_key')
    if data is None:
        data = Prosthesis.objects.all()
        cache.set('my_key', data, timeout=300)  # 5 минут

ВОПРОС: F expressions
  F() — ссылка на значение поля в БД, операция выполняется на стороне БД.
  Примеры:
    from django.db.models import F
    # Увеличить цену всех протезов на 10%:
    Prosthesis.objects.update(price=F('price') * 1.1)
    # Найти протезы где цена > старой_цены (два поля одной записи):
    Prosthesis.objects.filter(price__gt=F('old_price'))
  Преимущество: не нужно загружать объект в Python — операция в SQL.

ВОПРОС: The Http404 exception
ГДЕ СМОТРЕТЬ: catalog/views.py — prosthesis_detail()
  from django.http import Http404
  try:
      prosthesis = Prosthesis.objects.get(pk=pk)
  except Prosthesis.DoesNotExist:
      raise Http404('Протез не найден')
  Альтернатива (короче):
      prosthesis = get_object_or_404(Prosthesis, pk=pk)
